# How It Felt

An interactive museum of ordinary experiences from 2026, built for the people of 3026. Each exhibit is a small playable simulation: waiting for a reply that turns out to be "ok", holding still to make a 1% battery last, wiping rain off a window. The future will keep our objects. This piece sends them the feelings.

Built with p5.js for Project B (Dear Future), Creative Coding Lab, Fall 2026.

Live: https://kden41999.github.io/how-it-felt/
